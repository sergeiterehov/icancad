# ADR 0037 — Transform: move, turn and scale objects

Status: accepted

## Context

The model carried a `transform` operation, but it was only a placeholder: one
`bodyId`, no tool-rail entry, no inspector, and the rebuild answered
`NOT_IMPLEMENTED`. Moving a body meant editing the translation of the
primitive that made it, which only works for primitives; a body built by an
extrude could not be placed at all.

Moving and turning are the most frequent housekeeping operations in any model:
a part is drawn where it is easy to draw, then placed where it belongs. The
same operation should serve a whole group of objects as if it were one body,
and it should be reachable from the 3D view.

## Decisions

| Area       | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |                                                                                                                                                                                                                                                          
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |                                                                                                                                                                                                                                                          
| Inputs     | The operation owns two lists: `bodyIds` (solid bodies) and `sketchIds` (sketches). It is offered by the objects themselves — the context menu of a selection carries `Transform` when every picked object can be moved (a mesh cannot) — and the lists are then edited with one pencil in the section header, by clicking bodies or sketches in the 3D view or the model tree. Imported meshes are never targets.                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |                                                                                                                                                                                                                                                          
| Parameters | `transform.translation` (mm, X/Y/Z), `transform.rotation` (degrees, X/Y/Z) and `transform.scale` (uniform factor) are ordinary parameters, so they accept formulas like every other number. The scale is *written* as a percentage, in the panel and in the drag chip, because that is how a drawing is measured by hand; the factor is what the model, the matrix and the sketches use, so a typed percentage is divided by a hundred on its way in. A field that is driven by a formula loses its handle.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Placement  | `M(p) = P + R·(s·(p − P) + t)`: the selection is scaled and turned around the pivot `P`, and the offset `t` is measured **along the turned axes**, so the position fields and their arrows follow the object rather than the world. `R = Rz·Ry·Rx`, the order imported meshes are placed in, so a turn reads the same wherever it is written down.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |                                                                                                                                                                                                                                                          
| Pivot      | One pivot for the whole selection: the centre of the bounding box of everything the operation moves, measured before the operation. Every body and sketch turns and scales around that one point, so a group behaves like one rigid piece. There is no switch: the alternatives (each object on its own, or an object's own anchor) differ from it only for groups and only in ways that are hard to predict, and a lone symmetric object is the same in all of them. |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
| Bodies     | Each body is one kernel `transform-shape` copy at `M`. The body keeps its id, owner and face map, because the copy has the same topology at another pose; later references to its faces and edges still resolve, and the tree keeps its name and colour.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |                                                                                                                                                                                                                                                          
| Sketches   | A sketch is moved as its result. On its place in the history the operation replaces the frame the sketch would use (`origin = M(origin)`, axes and normal turned by `R`) and scales its 2D geometry by `s`, which scales the drawing exactly as the affine scales every point of it. The stored sketch feature is not touched, so suppressing or deleting the operation returns it to the pose the user drew.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |                                                                                                                                                                                                                                                          
| Order      | A sketch has to stand before the operation that moves it; the usual dependency check reports a transform dragged in front of its sketch as `DEPENDENCY_AFTER_USE`. Bodies are referenced by their creating operations the same way.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |                                                                                                                                                                                                                                                          
| Preview    | The edited operation is built against the state before it. Moved bodies are drawn solid at their new pose (a transform has no delta: the body itself is the result), and picked against their moved shape. Moved sketches are drawn from the geometry the operation produces. While a handle is being dragged the difference between two placements is applied to the meshes and sketch curves already on screen, so the preview follows the pointer without waiting for the kernel; the rebuild that follows publishes the exact result.                                                                                                                                                                                                                                                                                                                                         |                                                                                                                                                                                                                                                          
| Handles    | A move gizmo (three arrows and a view-plane grip) that turns with the operation, three full-circle rings on the object’s own axes, and one yellow square for the uniform scale. A ring drag turns the object around the axis that ring shows and writes the resulting orientation back as the Euler angles the fields hold; the rings ride half again as far out as the arrows, so a ring never catches the pointer aimed at a translation. A plane drag is read back through the turn, so it moves the same axes the fields show. The pivot and the size the scale grip counts against are measured by the rebuild on the state before the operation and published with the preview; the handles are drawn where the operation carries that pivot (`M(P) = P + R·t`), so the gizmo rides along with the geometry it moves instead of being left behind, and a drag taken from a handle keeps its measured pivot for the matrix. Every gesture is one undo step and is applied to the values the operation had when the grab started, so repeated drags do not accumulate rounding. |                                                        
| Errors     | A target that is gone is reported on its row (`UNKNOWN_BODY`, `MISSING_SKETCH`), and a status that no longer has a B-rep as `BODY_NOT_SOLID`. An empty list is configuration in progress, not a failure, and a fresh operation without targets is discarded when it is closed like any other unused tool.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |                                                                                                                                                                                                                                                          
| Arrays     | A transform is not a repeatable operation: its difference is a moved body, not material, so repeating it as a delta would copy the body and the space it left.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |                                                                                                                                                                                                                                                          
| Format     | The placeholder never had a writer, so no saved document can carry one: the field became two lists without a schema version bump; a `center` written by an intermediate build is dropped by the parser.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |                                                                                                                                                                                                      

## Consequences

- A body moved by a transform is still the same object: later fillets, shells
  and booleans that name it keep working, and its creating operation keeps
  owning it.
- A sketch moved by a transform is only moved from that point of the history
  on. An extrude that consumes the sketch therefore is affected only if it
  comes after the transform; one that already ran before it keeps the shape it
  built.
- Editing the transform is idempotent: it is always applied to the authored
  state of its targets, never to its own previous result, so typing a new
  translation or dragging a ring replaces the old one instead of adding to it.
- A position is read in the object's own frame: turning an object leaves the
  numbers alone but moves the object, because the same offset now points along
  the turned axes. That is what keeps a drag and the field it writes the same
  number.
- A project can hold a transform whose target list is incomplete; the operation
  builds nothing until a target is picked, and closing it removes it.
- Moving a sketch does not rewrite its constraints or dimensions. The sketch
  editor keeps showing what was drawn; the transform is a placement of the
  result, the same way a later operation does not edit what an earlier one
  stored.
