# ADR 0043 — Sketch selection, group moves and compound tool buttons

Status: accepted

## Context

The sketch editor could select several entities, but dragging one of them collapsed the selection and moved only that entity. There was no box selection, which every CAD program offers as two gestures: a window that takes only what it fully encloses and a crossing box that takes everything it touches. The tool rail also had one button per entity kind, and adding the elliptical arc made that list longer than the rail should carry.

## Decisions

| Area                 | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Group drag           | Pressing an entity that is part of a set keeps the set; a drag moves every selected curve by the pointer delta. A press on a point handle still moves that point alone, with the selection preserved. A click without a modifier on an entity of a set does not collapse it; a click on another entity or on empty space does.                                                                                                                  |
| Group solve          | A drag pins every control point of every dragged entity first, so the shapes the user drew travel rigidly instead of being re-solved into shapes the constraints allow. If those pins conflict, one control point per entity follows, then the single-entity pin ladder, so a group that cannot move together still moves the grabbed curve the way it always has.                                                                              |
| Frozen geometry      | Geometry the solver reports without a degree of freedom is never dragged, and neither is a member of the selection that is frozen: translating it would only last until the next solve, which reads as the whole sketch jumping. A frozen curve therefore stays put while the rest of the group follows the pointer.                                                                                                                            |
| Marquee points       | A box also takes the control points it covers, so one end of a curve can be selected on its own. An entity the box takes whole keeps only itself, because its points are then part of it. A box inside a circle that encloses nothing takes the centre, not the circle.                                                                                                                                                                         |
| Ellipse tool         | The ellipse is drawn from three points: the centre, the end of the first half-axis, and the length of the other one. The first half-axis also turns the ellipse, so the tool draws rotated ellipses like the elliptical arc does, and both share one frame helper.                                                                                                                                                                              |
| Draft guides         | While an arc, an elliptical arc or an ellipse is being drawn, the construction the draft implies is drawn dotted at one pixel: the whole circle an arc is cut from, the whole ellipse an elliptical arc belongs to, and the axes of either. The solid preview stays the shape that the next click will create.                                                                                                                                  |
| Draft markers        | A click names a centre, an axis or an angle rather than a point of the curve, so the marker of that step is drawn where the finished entity will carry it: on the circle of an arc and on the ellipse of an ellipse or an elliptical arc. Only a step that lands under the pointer — the centre, or the radius of an arc and of a circle — is drawn at the pointer; every other marker, including the step in progress, sits on the shape.      |
| Draft guides         | The guide of an ellipse and of an elliptical arc is the whole ellipse, dotted, with both axes, from the first click: before the second half-axis is picked the ellipse is drawn half as tall as it is long. Spokes end on the markers, so an angle is read from the shape rather than from the pointer.                                                                                                                                         |
| Arc snaps            | Both ends of an arc take a `point-on-line`, `point-on-circle` or `point-on-ellipse` when they are drawn on a target, so each end is anchored where it was clicked. An arc does not take a tangency from a curve snap: tangency leaves the endpoint free to slide along the curve, and the solver then moves the whole arc away from the click. A circle keeps it, because its radius click names a tangent circle.                              |
| Elliptical arc draft | The ellipse it will be cut from is the dotted guide for the whole draft; the arc itself is drawn solid only once both ends are named, so the two radius steps and the first end never paint a solid ellipse that is not yet the shape.                                                                                                                                                                                                          |
| Elliptical arc snaps | Both ends of an elliptical arc take a target like any other point of the sketch — a point to coincide with, or a curve to lie on. The click that names the minor half-axis does not: it only gives a length across the major axis, so a target there could not become a constraint.                                                                                                                                                             |
| Compound press       | The main half of a split button picks the tool it shows, which is the variant last used in that group; it only starts the base tool while the group shows the base tool.                                                                                                                                                                                                                                                                        |
| Pointer marker       | A creating tool draws the point its next click would place, under the pointer, because an arc or an ellipse preview carries no marker of its own until the shape exists. The marker takes the magnet colour when the point comes from a snap, so both the point and the snap are seen before the click.                                                                                                                                         |
| Finger press         | A finger's tap is additive, but it is applied when the pointer lifts: pressing one member of a set to drag it keeps the set and moves all of it, and a tap without travel still toggles that member out. A press on an object outside the set takes the set over as soon as the finger travels.                                                                                                                                                 |
| Pinch                | The second finger belongs to the camera. It cancels the box a first finger had begun, restoring the selection that box started from, drops a pending tap, and puts back the geometry a first finger had already begun to drag. It never starts a box or a drag of its own.                                                                                                                                                                      |
| Long press           | A finger that rests on a split tool group opens its variant list, so a tablet reaches the variants without the 11 px chevron; the tap that ends the hold does not also start the base tool. A mouse keeps the chevron.                                                                                                                                                                                                                          |
| Point sizes          | Control points are handles only while the sketch is edited: outside the editor they are markers on a drawing and are drawn at half the size. The point under the pointer grows by two pixels in both cases, the same step the sketch line grows by.                                                                                                                                                                                             |
| Fixed points         | A point a fix constraint pins is drawn in the frozen colour straight from the constraints, so it reads as fixed before the first solve reports the frozen entities. Corner cases such as a fixed end of a free line colour that end only.                                                                                                                                                                                                       |
| References           | Reference values describe geometry instead of constraining it, so they sit under the dimension chips and under the geometry: a chip only takes the pointer where no curve is beneath it, which the overlay decides per move with a pick through the viewport. Under the pointer a value rises above the other values so it can be read, and hovering it lights its geometry in the pointer's blue, because a press there selects that geometry. |
| Chips in a drag      | A press that starts on the canvas turns every chip transparent to the pointer, so a drag or a marquee that passes over a value keeps running. A press that starts on a chip leaves it interactive, which is what makes a value double-clickable while editing.                                                                                                                                                                                  |
| Lists                | The geometry list and the constraint list of a sketch read as one list: the text size of the first, the violet text highlight of the second, and the colour the sketch is drawn with when it differs from the default. Icons keep the colour that carries their state.                                                                                                                                                                          |
| Finish button        | When the solver cannot move anything in the sketch, the button that leaves it turns the green the fully constrained geometry is drawn in, so a finished sketch is visible before pressing it.                                                                                                                                                                                                                                                   |
| Marquee              | With the Select tool, a drag that starts on empty space draws a box. Left to right is a window (only fully enclosed geometry); right to left is a crossing box (any geometry it touches). The box is drawn in the sketch overlay, solid for a window and dashed for crossing, and the selection updates live while the pointer moves.                                                                                                           |
| Marquee input        | The box works for every pointer. Inside a sketch one finger already belongs to the editor, and two fingers remain the camera, so a finger drag on empty space can select without fighting the view.                                                                                                                                                                                                                                             |
| Marquee contents     | Fundamental geometry — the origin and the two axes — is a reference, never part of a box selection.                                                                                                                                                                                                                                                                                                                                             |
| Compound buttons     | The circle button is a split control: its main part always starts the circle tool, and a slim chevron opens a menu with circle and ellipse. The arc button works the same way for the circular arc and the elliptical arc. When a variant is the active tool, the main part shows its icon and the group stays highlighted, but pressing it still starts the base tool.                                                                         |

## Consequences

- Selection is a stable set while the user works with it, so a group is moved as a group without re-selecting it.
- The marquee needs the sketch-plane point under the pointer, so the viewport exposes `sketchPointAt` beside `snapSketch`.
- The rail has room for more variants without another full-width button; a variant without its own shortcut is reached through the chevron.

## Amendments

- Escape takes the selection first: with geometry or a constraint selected it clears that and stays in the sketch, and only the next press returns to Select or leaves the sketch. A tool that is still drawing keeps its own order — the draft is rewound before anything else.
- Frozen is decided by moving each entity in the solver, not by the global degree of freedom, so the comparison that reads the answer is measured in millimetres and not in a fraction of the coordinates. It used to scale with the place of the geometry, and a sketch of two metres made the tolerance wider than the quarter-millimetre step the probe moves a point by: every entity then looked unmoved, and curves with one degree of freedom left — a construction line sliding along a fixed one — were painted as fully constrained. A moved state is proved by holding the point where the solve put it and solving again: a pin is an equation the solver may satisfy by giving up a relation it contradicts, while a held parameter cannot be dropped, and asking the solver to re-solve freely proves nothing because the sketch keeps its other degrees of freedom.
