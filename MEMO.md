- Трансформация
Перемещение, вращение и изменение масштаба.
Опеарция позволяет настроить внутри последовательность этих действий.
Есть ручки в 3д, которые позволяеют выполнять действия, автоматически добавляя их в список (одного типа соединяются: подвинули, еще раз подвинули - объединяется в одно действие).
Должен поддерживать множественный выбор трансформируемых объектов, к ним все будет применен список действий. Выбирать можно объекты целиком (сетку, скеч, тело и любые другие объекты в 3д пространстве модели).

- Соединение в действиях трансформации
Это действие аналог сборки, только в режиме трансформации.
Самый тривиальный вариант: выбираем две грани, и объекты перемещаются так, чтобы грани совместились (конечно одна грань должна быть в трансформируемых объектах, другая - вне их).

- Инструмент ребра жескости.
Выбираются ребра или грани (извлекаются ребра), настраивается толщина и направления (грани, до которых вести ребра).
Можно, как в выдавливании выбрать отдельные тела, к которым применяется операция.
Если ребро при вытягивании выступает за выбранную грань, то оно обрезается вдоль направления, параллельного вытягиваемого ребра.

- Булевы операции.
Табы выбора операции
- вычитание - из тел из первого списка вычитаются тела второго
- пересечение
- объединение
Два списка выбираемых тел, как выбор тел в выдавливании. Нельзя добавлять одно тело одновременно в 2 списка.
В заголовках обоих списков есть переключатель "Сохранить", который не удаляет исходные объекты из списка после операции. По умолчанию выключен.
Операция всегда создает новые тела, а не меняет исходные.

- Компоненты
Компонент - это параметризованный набор операций.
Для этого нам нужно научиться вводить названия переменных в инпуты операций.
Как это будет работать: каждый параметр в любой операции может содержать как фиксированное значение, так и формулу - это архитектурное решение. Все операции нужно порефакторить.
Пусть для пользователя это будет строка, которая начинается с символа "=" - так формула отличается от простого текстового значения. Синтаксис формул - python expression.
В принципе мы планировали в будущем добавить поддержку python скриптов, поэтому, если имеет смысл, использовать для этого единый парсер/интерпретатор.
Каждый экземпляр компонента - это отдельная операция, которая прокручивает операции изолированно от модели.

- Форма для параметризации
Форма - это суперобъект. Оно описывается декларативно: инпуты, типы, ограничения, множетсва... Элементам присваиваются идентификаторы. На идентификаторы можно ссылаться из формул, например так `=form1.box_height.value` или так `=box_form.ribs[3].width.value / box_form.ribs.size`.

- Сборка
Это отдельный супер объект, куда можно добавить тела из моделей.
Должен быть режим взаимодействия со сборкой, чтобы проверить механику.
Давай обсудим варианты опираций сборки и нюансы работы режима.
В сборке можно создавать экземпляры компонентов.

- Инструмент шестеренка в скече.
Добавляется после проекции.
Инструмент - это отдельный тип сущности. Он позволяет динамически создавать какую то геометрию внутри скеча.
У инструмента шестеренка свои настройки: модуль, и количество зубьев - для начала. Меняем настройки, геометрия перестраивается. Конечно, нужно помнить про идемпатентность. Этагеометрия стилистически выглядит, как геометрия проекции. В контекстном меню у такой геометрии есть пункт - Отвязать инструмент, которая удаляет инструмент, и делает геометрию обычной.
Другие инструменты не обязательно должны делать динамическую геометрию, они могут разово вставлять обычную геометрию, обхект такого инструмента не создается в скече.
Можно подумать о том, чтобы проекция тоже была инструментом.
Давай подумаем над концептом...
